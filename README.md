# مركز قيادة المدار — محاكي النظام الشمسي

تجربة تعليمية عربية تفاعلية مبنية بالكامل بملفات HTML وCSS وJavaScript، وتُقدَّم مباشرة من جذر المستودع على Vercel دون خادم أو قاعدة بيانات أو خطوة بناء.

## التجربة

- استكشف الشمس والأرض والقمر والمريخ والمشتري في مشهد Three.js مع النجوم والمدارات والتحكم بالكاميرا.
- افتح ملفات تعليمية عربية لكل جرم سماوي، تشمل الجاذبية والغلاف الجوي ومهمات ناسا.
- قبل الإطلاق، افتح **ورشة الصاروخ** واختر الوجهة: القمر أو المريخ أو المشتري.
- صمّم المركبة باختيار قطع من **٢٦ خياراً** موزعة على المحركات والخزانات والمعززات والأجنحة والدروع والحمولات، وشاهد تغيّر النموذج ثلاثي الأبعاد.
- اضبط قوة المحرك وامتداد الأجنحة وحمولة الوقود، ثم شغّل اختبار التحمل. لا يظهر زر إطلاق المهمة إلا إذا اجتاز التصميم الفحوص التعليمية.
- للمشتري، الاختبار مخصّص لدخول طبقة سحب افتراضية؛ فالمشتري عملاق غازي ولا يملك سطحاً صلباً للهبوط.

## طريقة النشر

اجعل جذر المستودع هو مجلد النشر في Vercel. نقطة الدخول هي `index.html`؛ لا يلزم أمر بناء أو تثبيت حزم. تُحمّل مكتبة Three.js من CDN، بينما توجد خرائط الكواكب محلياً في `textures/` لتجنب مشكلات CORS.

## ملاحظة عن المحاكاة

مؤشرات الدفع إلى الوزن، وميزانية تغيّر السرعة، وضغط وحرارة الوجهة هي **نموذج مبسّط للشرح واللعب**، وليست بيانات تصميم أو ضمان سلامة لصاروخ حقيقي. يعرض الاختبار قيماً تقريبية وفق خيارات اللاعب وملف الوجهة التعليمي.
